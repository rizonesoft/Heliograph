# The Heliograph identity

Handoff: two sessions make an H, and one beam of light passes between them, as a job passes to one taker. The arms are in the logo's blues and the beam is cyan glass over both. Chosen by the owner on 2026-11-24.

| File | Use |
| --- | --- |
| `icon/icon.svg` | 48 pixels and larger |
| `icon/icon-16.svg`, `-20`, `-24`, `-32` | Their own drawing, on whole pixels |
| `icon/glyph.svg` | One colour, in the text colour around it |
| `icon.ico`, `png/` | `helio.exe` and everything that takes a picture |
| `wordmark-dark`, `wordmark-light` | The name, as SVG outlines and PNG; the mark is its H |
| `banner-dark.png`, `banner-light.png` | The head of the README |
| `social-preview.png` | GitHub, Settings, Social preview |
| `badge-dark.png`, `badge-light.png` | Projects whose sessions use Heliograph |

The rules are those of Impossible OS: a 48 grid with the art in 4 to 44, seen from the front, lit from above, no outlines, the logo's blues. The wordmark is set in Plus Jakarta Sans, the banner in Selawik and Cascadia Code (all OFL). `tools/brand.py` renders everything but `icon/`. The windows in the banner show the program's own words.
