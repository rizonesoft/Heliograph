## Adversarial

1. **P1. A keyed retry can reopen a completed job.** Path: a sender retries while the first inbox of the day archives the same request. Evidence: traced `engine/store.c:459` and `engine/store.c:481`. Suspend the retry after its archive lookup returns missing, let the archiver finish removing the live post and links, then resume the retry. Its create-only write now succeeds. The original ID has a fresh live post with no steps, so another `take` can succeed. The test at `tests/test_helio.py:1196` starts the retry only after archiving finishes.
2. **P2. A linked archive month can cause deletion of the only copy.** Path: a restored or manually arranged store has an archive month directory linked back to `messages`.
